会話クラッシャー晒し機

〜 会話の「隙間（沈黙）」を可視化・戦犯公開処刑 〜

チーム: 隙間ハンター | 発表時間: 2〜3分
PROBLEM / 日常の違和感

誰かの発言の後、急に「シーン……」となったことは？

[ 突然の空白 ]

会話の停止

楽しく話していたのに急に会話が止まる

[ 気まずい空気 ]

犯人探し

「誰のせい？」と言い出せない隙間

[ 解散の危機 ]

沈黙の固定化

会話が完全に凍結して気まずい沈黙

誰も言えない真実（戦犯）を、テクノロジーで白日の下に晒す！
SOLUTION / 解決策

『会話クラッシャー晒し機』の仕組み

1

QRコードで各自のスマホが監視マイクに

音声内容は送らず、1bitの発話判定のみ持ち寄るプライバシー保護設計。

2

沈黙検知で大画面に直前の発言者を晒し上げ

会話が止まった瞬間からミリ秒単位でカウントアップ。直前の発言者を名指し！

3

5秒で巨大スタンプ飛び出し

「その発言で！ピタッと止まった…」が集中線とともにドカンと出現。

4

沈黙ブレイカーMVP表彰

止まった会話を再開させた人を大量の紙吹雪で祝福し、ポジティブに回収。

※ 1端末＝1マイクの分散マイクアレイ方式でクロストークを自動分離

CONCLUSION / まとめ

テーマ「隙間」への回答

POINT 1

隙間を無理に埋めない逆張りの発想

会話の隙間（沈黙）を気まずいものとして隠すのではなく、隙間を作った戦犯を晒して笑いに変えることで、結果的に会話が爆発的に盛り上がる。

POINT 2

壊れない技術選定

Web Audio API / AudioWorklet ＋ Node WebSocket。外部音声APIや非公式ボットに依存せず、ブラウザ標準技術だけで完結する堅牢なアーキテクチャ。
