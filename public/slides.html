会話沈黙可視化システム

会話の「隙間（沈黙）」のリアルタイム検知と表示

STEM Summer Hackathon 2026 参加作品 | 発表時間: 約 2〜3分
PROBLEM / 課題

会話中の沈黙発生と状況把握の難しさ

[ 発話の途絶 ]

会話停止

発言直後に全員が沈黙する状態の発生

[ 状況の不透明さ ]

直前発言の特定

誰の発言後に沈黙が生じたかの認識の曖昧さ

[ 時間の不可視性 ]

沈黙時間の長さ

沈黙が何秒間続いているかの客観的計測の不在

発話状態と沈黙継続時間を客観的なデータとして画面に可視化する
SOLUTION / 解決策

分散マイクによる沈黙時間計測システムの仕組み

1

QRコード接続とエッジ発話検知

音声は送信せず、ブラウザ内AudioWorkletで発話判定（RMS）のみをWebSocket送信。

2

沈黙時間の計測と直前発言者の表示

全員の音声入力停止から沈黙秒数をカウントし、直前の発言者名を画面に表示。

3

5秒以上の沈黙でスタンプ画像を表示

沈黙が5秒を超えた段階で指定スタンプ画像（その発言で会話がピタッと止まった）を表示。

4

発話再開者の検知と記録

沈黙を終えて最初に発話した参加者を検知し、沈黙救出回数として集計・表示。

1端末＝1マイクの分散マイクアレイ方式で同室クロストークを自動分離

CONCLUSION / 技術構成 & 発展性

エッジ処理基盤と Gemini / 低遅延AI連携による発展性

現行実装

エッジVAD ＋ 技術者倫理の遵守

Web Audio API / AudioWorklet ＋ Node WS。端末内メモリで即時破棄し、15ms未満の低遅延かつ倫理基準を完全遵守。

発展性

Gemini 2.0 Flash / Nano 連携

超低遅延・軽量LLMと連携し、沈黙発生時に会話再開のための話題候補をリアルタイム生成する機能への拡張。

会話における「隙間（沈黙時間）」をミリ秒単位で測定・可視化し、客観的データとして提供する
