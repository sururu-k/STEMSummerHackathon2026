## Slide 2: 課題提起
```
┌────────────────────────────────────────────────────────┐
│   日常の課題：発言後に生じる沈黙と状況把握の困難さ     │
├────────────────────────────────────────────────────────┤
│   ・会話の停止：発言直後に全員が沈黙する状態の発生     │
│   ・直前発言の特定：誰の発言後に沈黙したかの曖昧さ     │
│   ・沈黙時間の不可視性：何秒間続いているかの未計測     │
└────────────────────────────────────────────────────────┘
```
**トーク原稿 (目安: 30秒)**:
> 「複数人で会話している際、誰かが発言した直後に会話が止まり、そのまま沈黙が続いてしまうことがあります。誰の発言の後にどのくらい沈黙が続いているのかを客観的に把握することは困難でした。」

---

## Slide 3: プロダクト概要
```
┌────────────────────────────────────────────────────────┐
│   会話沈黙可視化システム の仕組み                      │
├────────────────────────────────────────────────────────┤
│   1. 各自のスマホをマイク端末化（QRコードで接続）       │
│   2. 沈黙発生時、直前の発言者を特定                   │
│   3. 大画面で沈黙秒数をカウントアップ表示             │
│   4. 5秒以上の沈黙で指定スタンプ画像を表示             │
│   5. 発話再開者を検知・集計                            │
└────────────────────────────────────────────────────────┘
```
**トーク原稿 (目安: 40秒)**:
> 「本システムでは、各自のスマートフォンがマイク端末となります。音声データ自体は送信せず、端末内で発話判定のみを処理します。全員が沈黙すると直前の発言者と沈黙継続時間が大画面に表示され、5秒を超えると指定のスタンプ画像が表示されます。」
