## Slide 3: プロダクト概要
```
┌──────────────────────────────────────────────────────────┐
│              会話クラッシャー晒し機                      │
│   〜 会話の「隙間（沈黙）」を可視化・戦犯公開処刑 〜     │
│                                                          │
│              STEM Summer Hackathon 2026                  │
└──────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────┐
│   1. 各自のスマホが「発話監視マイク」に（QRで即参加）  │
│   2. 沈黙が発生した瞬間、直前の発言者を特定            │
│   3. 大画面で秒数カウントアップ ＆ 公開処刑！          │
│   4. ❄️【NEW】軽量LLMが「なぜ場が冷えたか」を辛口分析 │
│                                                        │
└────────────────────────────────────────────────────────┘
```
**トーク原稿 (30秒)**:
「審査員や参加者がQRコードを読み込むだけで、各自のスマホが監視マイクになります。
会話が止まった瞬間、大画面の沈黙カウンタが爆速で跳ね上がり、『〇〇の発言で会話凍結中！』と名指しで晒し上げます。さらに軽量LLMが『なぜ今の発言で場が冷え切ったのか』をリアルタイムに毒舌解説します。」

## Slide 5: 技術のこだわり & テーマへの回答
```node_modules
┌────────────────────────────────────────────────────────┐
│                                                        │
│   技術構成 & テーマ「隙間」への着地                    │

│                                                        │
└────────────────────────────────────────────────────────┘
```
**トーク原稿 (30秒)**:
「音声そのものは一切サーバーへ送らず、端末内のAudioWorkletで発話判定だけを集約するプライバシー完全保護設計です。
会話の隙間を無理に埋めようとするのではなく、隙間を作った戦犯を晒し上げて笑いに変える——これが我々のテーマ『隙間』への回答です。ありがとうございました！」
