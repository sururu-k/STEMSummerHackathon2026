# ハッカソン実装計画書: 会話沈黙可視化システム (Silence Tracker)

## 1. 開発方針・スコープ

- **テーマ**: 隙間
- **プロダクト名**: 会話沈黙可視化システム (Silence Tracker)
- **コア機能**:
  1. 各自のスマートフォン端末をWebブラウザでマイク化（QRコード接続）。
  2. 端末内（AudioWorklet）で発話判定（RMS）のみを計算し、音声データは送信せず破棄（技術者倫理遵守）。
  3. 全員が沈黙した瞬間から沈黙秒数をミリ秒単位で計測。
  4. 直前の発言者名と沈黙継続時間を大画面にリアルタイム表示。
  5. 5秒以上の沈黙で指定スタンプ画像（その発言で会話がピタッと止まった）を表示。
  6. 沈黙終了時に最初に発言したユーザーを検知し、沈黙救出回数として集計。

---

## 2. システム構成

```
[参加者スマホA] ──(発話判定 10Hz)──┐
[参加者スマホB] ──(発話判定 10Hz)──┼─► [Node.js WebSocketサーバー] ──► [大画面プロジェクター表示]
[参加者スマホC] ──(発話判定 10Hz)──┘   (音量比較 / 沈黙判定 / 状態管理)    (沈黙タイマー / スタンプ表示)
```

---

## 3. 実装モジュール

1. **エッジ音声処理 (`public/audio-worklet-vad.js`)**:
   - Web Audio API / AudioWorklet による 300Hz〜3400Hz バンドパスフィルタ
   - RMS音量計算と適応ノイズフロア閾値判定
2. **WebSocket サーバー (`server/index.js`)**:
   - 分散マイクの最大音量比較（クロストーク分離）
   - 沈黙ステートマシン（沈黙時間・直前発言者・救出者記録）
3. **大画面ダッシュボード (`public/display.html`)**:
   - 沈黙カウンタ、タイムラインCanvas、スタンプ表示、ランキング
4. **マルチ端末スタジオ (`public/studio.html`)**:
   - 大画面とスマホ3台を1画面に統合した実演シミュレータ
5. **Marp 発表スライド (`md/slides.marp.md`)**:
   - 発表用スライド（HTML/PDFエクスポート対応）
